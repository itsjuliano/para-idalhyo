🌸 Para Idálhyo — 12 de Junho 🌸

"Nem todo começo tem data exata — o nosso tem. E vale cada detalhe."

Este é um espaço digital e imersivo construído com muito carinho para celebrar o primeiro Dia dos Namorados de Juliano & Idálhyo. Mais do que um projeto de código, este site é uma cápsula do tempo interativa feita para guardar as nossas memórias, viagens e promessas de um futuro lindo juntos.

[Imagem de Pré-visualização do Site]

✨ Recursos Especiais & Microinterações

Para tornar a surpresa perfeita, o site foi polido com técnicas modernas de UI/UX e animações fluidas de alta performance:

🎬 Tela de Entrada Cinematográfica: Uma linda tela de boas-vindas minimalista com um coração pulsante. Ela serve para contornar o bloqueio de reprodução automática de áudio dos navegadores, dando início à trilha sonora exatamente no momento em que a história é revelada.

🎵 Equalizador de Áudio Ativo: Um botão de música flutuante que conta com um equalizador visual feito em CSS, subindo e descendo delicadamente ao ritmo da melodia ambiente.

✍️ Carta de Amor em Papel Macio: Substituímos o fundo plano da carta por um pedaço tridimensional de papel pautado amassado e dobrado. O espaçamento das linhas do caderno e o tamanho do texto foram calibrados cirurgicamente, finalizando com uma assinatura realista feita com a fonte cursiva Caveat.

📸 Galeria de Viagens Resiliente: Um mural interativo que registra os nossos momentos marcantes pelas cidades que visitamos (Pedro II - PI, Alcântara - MA, Teresina - PI e São José de Ribamar - MA). Conta com um sistema inteligente de fallback de imagens para evitar links quebrados.

⏳ Cronômetro do Amor: Uma contagem regressiva precisa que calcula os dias, horas, minutos e segundos restantes até o nosso próximo dia 12 de Junho.

🌸 Chuva Radial de Pétalas e Corações: Ao abrir a surpresa final, uma explosão orgânica de pétalas e pequenos corações em SVG se espalham pela tela através de cálculos otimizados pela Web Animations API nativa (GPU), garantindo extrema fluidez.

✏️ Efeito Typewriter: A frase final da surpresa é digitada letra por letra na tela, simulando uma máquina de escrever poética e interativa.

🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias limpas e sem frameworks pesados, garantindo performance instantânea tanto no celular quanto no desktop:

HTML5 — Estruturação semântica e acessível.

CSS3 — Variáveis nativas, animações de pulso, filtros de desfoque de fundo (glassmorphism) e pauta de caderno feita com gradientes lineares.

JavaScript (ES6+) — Manipulação de canvas em tempo real, lógica de cronômetro, renderização física de partículas, efeitos de digitação e Web Animations API para a explosão de corações.

FontAwesome — Ícones vetoriais modernos.

Google Fonts — Fontes editoriais Cormorant Garamond, DM Sans e Caveat.

🚀 Como Rodar este Projeto Localmente

Se quiser clonar o repositório e testar no seu computador:

Clone este repositório para a sua máquina:

git clone [https://github.com/itsjuliano/para-idalhyo.git](https://github.com/itsjuliano/para-idalhyo.git)


Garanta que a pasta do projeto possui a seguinte estrutura:

site-namorados/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── momento1.jpeg
    ├── momento2.jpeg
    ├── momento3.jpeg
    └── momento4.jpeg


Abra o arquivo index.html em qualquer navegador de internet!
